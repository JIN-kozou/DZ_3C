🔧 Quick Setup Guide

🔹Select the folder of the render pipeline you are using when importing the content. The demo scene is only compatible with the HDRP render pipeline, but it is for visual purposes only. Therefore, you do not need to import it. Just follow the instructions below.

URP:

1- Select your URP Asset (e.g., URP-HighFidelity-Renderer).
2- Go to Add Renderer Feature → Choose Full Screen Pass Renderer Feature.
3- Set Injection Point to Before Rendering Post Processing.
4- Drag the desired material into the Pass Material slot.
	⚠️ Make sure material names start with "M_" to enable parameter adjustments.

HDRP:

1- Right-click in your scene hierarchy → Volume → Custom Pass.
2- Set Injection Point to Before Post Process.
3- Click ➕ to add a new Custom Pass.
4- Drag your chosen material into the FullScreen Material slot.
	⚠️ Material names must begin with "M_" to allow parameter control.
